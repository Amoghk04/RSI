**Our default ratios on the pool (2171 tasks):** 40% `opt` / 20% `val` / 15% `select` / remainder unused holdout buffer (optional future ablations). Stratify by intent prefix (`mobile_data_issue`, `service_issue`, `mms_issue`) and by number of `|` segments in the task id (subtask-count proxy).

**Reward filter (adapter):** Prefer tasks whose `evaluation_criteria` use action/state rewards, not NL-assertion-only. Pin τ² commit; exclude or tag NL-only tasks in manifest metadata when the repo exposes `reward_basis`.

**Prototype budget:** configs use tiny `opt_batch` and rotating `val` subsets; the manifest still lists full split membership for reproducibility.
